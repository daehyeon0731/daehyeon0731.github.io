수채화 셰이더 #1 — 엣지 다크닝과 그래뉼레이션

WatercolorNPRGLSL

이 블로그 메인 화면의 배경은 하나의 프래그먼트 셰이더로 그려집니다. 실제 수채화에서 관찰되는 현상을 몇 가지로 나누어 근사했습니다.

1. 엣지 다크닝 (Edge Darkening)

물감이 마르면서 안료가 가장자리로 이동해 테두리가 진해지는 현상입니다. 밀도 필드 d에 대해 임계값 근처의 얇은 띠를 따로 계산해 더해줍니다.

float wet  = smoothstep(th, th + 0.18, d);
float edge = smoothstep(th - 0.004, th + 0.010, d)
           * (1.0 - smoothstep(th + 0.010, th + 0.055, d));
float body = wet * (0.22 + 0.22 * flow) + edge * 0.42;

2. 그래뉼레이션 (Granulation)

안료 입자가 종이 결의 움푹한 곳에 가라앉는 현상입니다. 종이 높이 노이즈로 안료 농도를 변조합니다.

body *= 0.82 + 0.36 * grain;

3. 글레이징 (Glazing)

수채화는 투명한 층을 겹쳐 색을 만듭니다. 각 레이어를 투과색으로 보고 곱해주면 감산 혼합이 됩니다.

col *= mix(vec3(1.0), indigo, aA);
col *= mix(vec3(1.0), rose,   aB);
